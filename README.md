## Engineering principles

- **Use what already works.** Integrate proven open-source tools instead of reinventing everything.
- **Local-first where it matters.** Prefer control over data, infrastructure and dependencies.
- **Evidence over assumptions.** Keep outputs traceable and distinguish measured facts from model suggestions.
- **Build for actual use.** Value simple operation, recovery and maintainability over unnecessary complexity.
